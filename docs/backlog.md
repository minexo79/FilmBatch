# 待辦與調查方向

## 後續調查想法（2026-10-22）

以下是本輪留下的調查方向，不代表已實作或已取得新一輪開發授權：

- **先取得原始案例，再判定修正位置。** Sony 調整無效與 iOS JPEG 偏紅都需要回報當時的原檔、機型及設定；保留 ICC／EXIF 與檔案雜湊，逐層區分解包、白平衡／profile、預覽、匯出及螢幕顯示。合成圖未重現不能否定回報，也不能拿換 decoder 或固定色偏補償當預設答案；[iOS 核對方法](evidence/ios-2026-10-20.md#ios-jpeg-色彩核對2026-10-22)可作重播起點。
- **讓每張照片的能力更容易辨識。** 可考慮依實際中繼資料提示內嵌鏡頭修正、gain map、語意遮罩及內嵌 JPEG 縮圖的適用範圍；沒有資料與控制項未生效必須分開。這是介面提示構想，尚未新增能力偵測或停用規則。
- **把暗部畫質與執行成本分開驗收。** 下一輪候選是更多相機／ISO／夜景、亮暗細線、膚色及飽和邊緣，分別量測降噪、紋理損失、暈光、代理預覽與全圖差異；GPU 單次處理時間、記憶體及真機取消另測，不沿用多次算圖診斷的耗時當效能結論。既有[研究與未取得的驗收](research/shadow-recovery-survey.md#可實作建議與尚未取得的驗收)仍適用。
- **解碼器變更維持證據門檻。** 只有受控比較確認影響正確性或可用影像資訊的差異，才另行評估修正；Sony 高光超出值與相機黑白位仍需各自的高光／校準證據，不因暗部功能已落地就重寫既有相容契約。
